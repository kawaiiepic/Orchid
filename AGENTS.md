# AGENTS.md – Orchid

Orchid is a **Flutter music player client** for the Eclipse addon protocol.
It is not an addon.

Protocol: https://eclipsemusic.app/docs  
UI kit: https://pub.dev/packages/shadcn_flutter (no Material)

## Layout

```
lib/
  main.dart              entry
  app.dart               ShadcnApp + theme
  models/addon.dart      Manifest, InstalledAddon, TrackResult, StreamInfo
  services/
    addon_service.dart   install, persist, search, resolve stream
    player_service.dart  just_audio wrapper
  screens/
    home_screen.dart     addons UI + search + results + mini player
```

Platform folders (`android/`, `ios/`, …) are generated by `flutter create .` and are not committed yet.

## Eclipse contract used

- Install: fetch `{base}/manifest.json`, require `id` + `name`
- Search: fan-out to addons with `resources` containing `"search"`
- Play: `GET {base}/stream/{id}` → set `just_audio` URL to `url`

Persist installed addons in `shared_preferences` key `orchid_addons_v1`.

## Rules

1. Stay on shadcn_flutter widgets/theme. Do not pull in Material/Cupertino unless interop is explicitly required.
2. Keep addon HTTP shapes compatible with the Eclipse docs.
3. Fail soft per-addon on search; surface stream errors to the user.
4. No secrets in the repo. Tokenized addon URLs live only in local storage.
